# Task 2 - Linear Regression

Implementation of a Linear Regression model using NumPy to predict house Sale Price

## What I did in the file:
- Preprocessed the dataset and handled missing value
- Applied one-hot encoding to categorical features.
- Performed feature scaling
- Converted the data into NumPy arrays
- Initialized weights and bias and updated them
- Implemented linear regression
- Trained the data using the dataset given and then tested it to get the predictions
- Compared these predicted values with the actual sale prices
